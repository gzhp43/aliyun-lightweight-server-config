## 轻量应用服务器和 ECS 怎么分

同样是阿里云的服务器，判断标准就一条：对带宽和内网架构有没有硬性要求。

带宽的差别，官方 FAQ 写得很清楚：轻量套餐内的公网带宽是出、入方向的峰值上限，不作为业务承诺指标，高峰期资源争抢时可能限速、丢包；对公网质量有强保障诉求的场景，官方推荐用固定公网带宽计费的 ECS。

更容易被忽略的是内网。轻量服务器默认使用专有网络 VPC，同一账号同一地域的多台轻量服务器之间可以内网互通，但和同账号下其他产品的内网默认互不相通——官方 FAQ 的原话是不能通过 VPC 内网直接关联云数据库 RDS。打算组“应用 + 独立数据库”的内网架构，从一开始就该选 ECS。

迁移这条路是双向的：轻量应用服务器与 ECS 实例之间支持数据无缝迁移，官方最佳实践里两个方向的教程都齐。起步选轻量、业务长大再搬 ECS，走得通。

## 下单前值得知道的几个限制

下面这些都写在官方 FAQ 和帮助文档里，推荐文章却很少提，每一条都可能实际影响使用：

1. 防火墙默认只放行 22、80、443 三个端口。数据库端口、面板端口要自己到防火墙规则里手动加，“服务起了却访问不了”多半是漏了这步。
2. 带宽是峰值上限，官方明确不作为业务承诺指标。标称的 200M、30M 在业务高峰期都可能限速，对下载速度敏感的应用要有预期。
3. 云监控插件可能失效。控制台里的内存、系统盘使用率靠云监控插件采集，重置系统之后插件可能失效，届时要手动重装，否则监控区域一片空白。
4. 被入侵的代价很高。CPU 使用率莫名冲到 80% 以上、还有未知进程持续向外发网络包，基本可以判定中招挖矿。因挖矿或被攻击被封的服务器，自助解封只有一次机会；解封后 3 天内再次检测出挖矿行为，会再次封停且无法解封。解封之后第一件事是备份数据。
5. 不支持过户。别抱着“买完以后转给别人”的打算。
6. 到期或欠费会进入“已禁用”状态。实例被锁定，续费或提交工单才能解锁，期间业务是停的，快到期时留意控制台提醒。
7. 备案问题。中国内地节点绑域名建站需要完成 ICP 备案；香港节点免备案，外贸站和着急上线的项目直接选香港。

## 买完之后：从创建到能访问的配置流程

流程就四步，顺利的话十几分钟走完。

1. 创建实例时选镜像——想省事用应用镜像，想要干净系统用系统镜像
2. 到防火墙规则里放行业务端口
3. 远程连接：控制台自带一键远程；习惯命令行就用 SSH 连 22 端口；连 Windows 服务器碰到 Credssp 报错，官方 FAQ 有专门的处理方法
4. 部署应用，公网 IP 直接在控制台的服务器卡片里看

连不上或访问异常，先跑控制台的自助诊断工具。LAMP 环境、FTP 服务器（基于 vsftpd）、Docker 部署、phpwind 论坛这类常见搭建任务，官方帮助中心都有分步教程，照着做就行。

## 几个高频问题的答案

**能升级配置吗？** 可以。业务变大后在控制台直接升级，不用换机器重装环境。

**数据安全吗？** 云盘用三副本技术，官方标称 99.9999999% 的数据可靠性；另有快照功能，随时备份、随时恢复云盘数据。

**有免费试用吗？** 阿里云试用中心目前主推的是云服务器 ECS 免费试用：企业用户 4核8G、5M 带宽、100G SSD，个人用户 1核1G、1M 带宽、40G 系统盘，时长都是 1 个月，需完成实名认证，且要在注册后 6 个月内申请。轻量应用服务器按包年包月售卖，想低成本试水的话，一年期 2核2G 参考价 68 元，试错成本本身不高。

**能防 DDoS 吗？** 自带云盾服务，可以防 DDoS 流量攻击，出现攻击时系统自动检测并清洗异常流量，攻击量特别大时会做黑洞处理。建议再装一层防护软件，把不常用的端口关掉。
